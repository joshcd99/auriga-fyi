Ember

Personal finance tracker · CS / technical · SOAR

Ember is a personal-finance tracker that lets a single user log transactions, categorize spend, and watch monthly trends. It's a full-stack web app I built end-to-end — frontend, API, persistence — and ship at ember.auriga.fyi.

Keywords: full-stack, personal finance, web app, REST API, database design, authentication, UX, self-hosted, Vercel.
